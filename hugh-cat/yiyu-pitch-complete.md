# 益屿 · 投资人讲稿（黄师宬版）

**时长：** 约 3 分钟

---

各位评委，大家下午好。我叫黄师宬，今天我带来的项目是益屿的社区活动管理平台。

我的项目给社区成员们提供更高效的活动组织与管理。我先阐述一下社区活动管理现有的痛点：用户报名混乱；缺少回忆沉淀；活动组织复杂。

平台做的事情就是要让管理数字化。我们有完整的活动管理，用户共享的活动回忆，AI 自动生成活动方案与复盘报告。用户点一点，就能发布一项活动，轻松组织起成员。

目前，项目计划从益屿空间内的辅助管理开始，拓展到益圈社区。在未来项目完全成熟后，还可以提供给更多的社区。

据估算，平台维护一年的花费在 4000-5000 元间。随着用户增加，维护成本的变化微乎其微。

---

那用户从哪里来？

目前从益屿空间自身的管理需求出发，每周 3 场活动来打磨产品。下一步面向益圈社区，覆盖 5-10 个社区组织。按照规划，一年内扩展到 20-50 个社区，触达上千名参与者。模式成熟后，全国 64.7 万个社区组织都是潜在的服务对象。

竞争对手呢？

说实话，活动行、会务通这些 SaaS 年费 3.6 万起，面向企业会议市场，不是我们的对手。我们真正的对手——Excel 加微信群。64.7 万个社区都在用这套免费但极其低效的方式管活动。我们要做的，就是给它们一个更好的选择。

最后一个问题，项目怎么活下去？

益屿是公益项目，不以盈利为导向，但不意味着不赚钱——恰恰相反，必须赚钱才能持续服务社区。

我们的收入模式很简单：基础版免费，单社区全功能随便用，吸引社区入驻建立口碑。专业版 ¥500-1,000 一年，多社区管理、AI 方案生成、SOP 模板库，4-8 个付费社区就能覆盖全年运营成本。再加上政府采购、公益基金会捐赠，覆盖 50 个社区时年收入 5,000-10,000 元，净利润率 80% 以上。

做这个项目，我不需要烧钱，也不需要融资烧流量。需要的只是让产品接触到真正需要它的社区。

益屿现在已经在线可用了。15,000 多行代码、17 个页面、25 个 API 接口，前后端全通，你可以直接访问体验。

一款工具，年成本 4,000 元，能让社区活动效率大幅提升——这个产品已经做出来了，现在需要的是把它送到需要的人手里。

谢谢大家。
