### ❌ 已修复的错误

#### 1. SearchPage.tsx - 筛选器状态闭包过期（已修复）
- **文件**：`pages/SearchPage.tsx`
- **问题**：`handleFilterChange` 中使用 `setTimeout(() => performSearch(), 0)` 触发搜索，但 `performSearch` 是通过 `useCallback` 创建的闭包，捕获的是**当前渲染周期**的 state 值。当 `onChange` 中先调用 `setCategory(newValue)` 再调用 `handleFilterChange()` 时，`performSearch` 读到的仍是**旧的** category 值。
- **影响**：切换分类/排序等筛选项时，搜索可能使用旧值，导致结果与用户选择不一致。
- **修复**：引入 `performSearchRef` 始终指向最新的 `performSearch` 引用，`handleFilterChange` 通过 ref 调用。
- **同样修复**：重置按钮和清空搜索按钮也使用了相同的 ref 模式。

#### 2. SearchPage.tsx - 防抖定时器未清理（已修复）
- **文件**：`pages/SearchPage.tsx`
- **问题**：`debounceRef` 中的 setTimeout 在组件卸载时未清理，可能导致内存泄漏或在已卸载组件上调用 setState。
- **修复**：添加 `useEffect` 清理函数。

#### 3. MyEventsPage.tsx - useCallback 依赖缺失（已修复）
- **文件**：`pages/MyEventsPage.tsx:21-36`
- **问题**：`loadCreated` 使用了 `user?.id` 进行过滤，但 `useCallback` 的依赖数组为空 `[]`。如果用户 ID 变化（虽然实际场景中不太可能），回调不会更新。
- **修复**：将依赖数组改为 `[user?.id]`。
