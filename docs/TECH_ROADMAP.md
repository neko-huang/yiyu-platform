| 风险 | 影响 | 应对措施 |
|------|------|---------|
| DeepSeek API 响应慢/不稳定 | AI功能体验差 | 增加缓存+降级策略 |

| 数据量增长快 | 性能下降 | 提前设计分库分表方案 |

## 团队协作规范

### Git 工作流
```
main (生产)
  ↑
develop (开发)
  ↑
feature/xxx (功能分支)
```

### 提交规范
- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档更新
- `style`: 代码格式
- `refactor`: 重构
- `test`: 测试相关
- `chore`: 构建/工具

### 代码审查
- 所有代码必须通过 PR 合并
- 至少 1 人 review 通过
- CI 测试通过才能合并
