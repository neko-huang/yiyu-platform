# 益屿内容定制方案

## 益屿空间定位

> **益屿** = 温榆河畔的社区生活空间  
> 一楼：咖啡馆 + 循环商店 | 二楼：活动空间 | 户外：温榆河畔 | 线上：益圈社群

---

## 一、空间 × 内容矩阵

### 🏠 一楼咖啡馆 — 「慢下来，聊起来」

**空间气质：** 温暖、松弛、有交流感  
**核心功能：** 日常社交、轻办公、社区入口

| 活动类型 | 方案名称 | 说明 | 频次 |
|---------|---------|------|------|
| ☕ 咖啡工坊 | **手冲咖啡周末课** | 益屿咖啡师教手冲，每月一款豆子 | 每周六下午 |
| 📖 换书角 | **「一本书换一杯」** | 带一本书来，换一杯咖啡，书留在循环商店 | 日常持续 |
| 🎨 微型展览 | **墙面策展人计划** | 每月一位益圈成员在咖啡馆墙面办个人小展（摄影/插画/收藏） | 每月更换 |
| 🗣️ 话题桌 | **「今天聊什么」** | 每桌放一个话题卡，陌生人也能聊起来 | 日常持续 |
| 🎵 午间弹唱 | **午间15分钟** | 本地音乐人午间即兴弹唱，不插电 | 每周三中午 |

### ♻️ 一楼循环商店 — 「让闲置流动」

**空间气质：** 环保、有故事、淘宝感  
**核心功能：** 闲置交易、环保教育、社区捐赠

| 活动类型 | 方案名称 | 说明 | 频次 |
|---------|---------|------|------|
| 🏪 周末跳蚤市场 | **益屿循环集市** | 温榆河畔户外摊位，闲置物品交换/售卖，摊主免费报名 | 每月最后一个周末 |
| 🧵 旧物改造工坊 | **「旧物新生」** | 带一件旧衣服/旧物件，现场改造成新东西 | 每两周一次 |
| 📚 图书漂流 | **益屿图书漂流计划** | 循环商店设漂流书架，自由取阅，读完放回 | 日常持续 |
| 🎁 礼物盲盒 | **「闲置盲盒」** | 把闲置包装成盲盒，随机交换，惊喜感满满 | 每月一次 |
| 🌱 环保挑战 | **21天零浪费打卡** | 益圈社群内打卡，完成挑战获益屿积分 | 季度活动 |

### 🏢 二楼活动空间 — 「一起玩，一起学」

**空间气质：** 灵活、多功能、有内容  
**核心功能：** Workshop、课程、聚会、分享

| 活动类型 | 方案名称 | 说明 | 频次 |
|---------|---------|------|------|
| 🧘 晨间瑜伽 | **温榆河畔·晨间流动** | 二楼活动空间，窗户打开，河风进来 | 每周六早7:30 |
| 🎬 主题放映 | **益屿放映室** | 每周一个主题，纪录片/独立电影/经典老片 | 每周五晚 |
| 🎲 桌游之夜 | **益屿桌游局** | 每周一个桌游，新手教学+欢乐局 | 每周四晚 |
| ✍️ 写作/手账 | **「静心两小时」** | 无干扰书写时间，提供纸笔和茶 | 每周三晚 |
| 💃 舞蹈/律动 | **益屿舞动课** | 零基础爵士/拉丁/摇摆舞体验 | 每两周一次 |
| 🧵 手工坊 | **手作系列课** | 皮具、花艺、陶艺、编织，每月轮换 | 每周日下午 |
| 🗣️ 开放麦 | **益屿开放麦之夜** | 脱口秀/故事会/诗歌朗诵，每人5分钟 | 每月第一个周五 |
| 💼 创业分享 | **益屿·创业者说** | 本地创业者分享真实经历，Q&A互动 | 每月一次 |
| 📖 读书会 | **益屿共读会** | 每月一本书，分两次讨论（上半/下半） | 每两周一次 |

### 🌿 温榆河畔 — 「走出去，动起来」

**空间气质：** 自然、开阔、治愈  
**核心功能：** 户外运动、自然体验、社区活动

| 活动类型 | 方案名称 | 说明 | 频次 |
|---------|---------|------|------|
| 🏃 河畔晨跑 | **温榆河晨跑团** | 沿河5km/10km，配速不限，跑完回咖啡馆早餐 | 每周六早6:00 |
| 🧘 河畔瑜伽 | **日出·河畔瑜伽** | 在河边草坪做流瑜伽，配合日出时间 | 每周日早5:30（夏）/6:30（冬） |
| 🐕 遛狗社交 | **益屿遛狗日** | 带狗来河边，狗狗社交+主人社交 | 每两周一次 |
| 🚴 骑行 | **温榆河绿道骑行** | 沿温榆河绿道，全程约20km，休闲骑 | 每月一次 |
| 🔭 观星 | **温榆河观星夜** | 在河边观测夏季银河/冬季星空 | 每月一次（好天气） |
| 🧹 河岸净滩 | **「守护温榆河」** | 公益净滩+水质检测，数据记录为环保报告 | 每季度一次 |
| 🧺 河畔野餐 | **益屿 picnic day** | 带野餐垫和食物，在河边享受慢周末 | 不定期 |

### 💬 益圈社群 — 「线上连接，线下见面」

**空间气质：** 温暖、互助、有归属感  
**核心功能：** 社群运营、信息发布、成员互动

| 运营方式 | 方案名称 | 说明 |
|---------|---------|------|
| 📱 社群矩阵 | **益圈微信群 + 益屿APP** | 活动通知、日常交流、二手交易、求助互助 |
| 🗳️ 内容共创 | **「我想在益屿办…」** | 每月投票，让社群决定下个月的活动内容 |
| 👤 会员体系 | **益圈会员** | 积分制：参加活动→攒积分→兑换咖啡/课程/商品 |
| 🏅 成就系统 | **益圈成就徽章** | 「咖啡品鉴师」「旧物改造王」「河畔跑者」等 |
| 🎂 生日会 | **益屿月度生日会** | 每月为当月生日的益圈成员办集体生日 |
| 📰 周报 | **益屿周末报** | 每周五推送：本周活动回顾+下周活动预告+推荐 |

## 四、mock 数据更新方向

基于以上方案，events.json 将围绕益屿实体空间重新设计：

- **益屿馆内活动**（咖啡馆+二楼活动空间）：约占 40%
- **温榆河畔活动**（户外）：约占 25%
- **北京其他场景**（合作场地/外出）：约占 25%
- **线上活动**（益圈社群）：约占 10%

所有活动标题统一带「益屿」前缀，标签统一含「益屿」tag，建立品牌认知。
