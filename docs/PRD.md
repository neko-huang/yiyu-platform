# 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
益屿是一个活动管理SaaS平台，服务于活动组织者（如社团、公司、社区）和活动参与者。平台提供从活动策划到复盘的全流程管理工具，通过AI辅助降低活动策划门槛，通过数据驱动提升活动质量。

### 1.2 目标用户
- **B端（管理端）**: 活动组织方，如「益屿」团队、社团负责人、企业HR
- **C端（用户端）**: 活动参与者、有办活动想法的个人用户

### 1.3 核心价值
1. **降低策划门槛**：AI辅助将模糊想法转化为可行方案
2. **提升运营效率**：标准化工具减少重复劳动
3. **数据驱动决策**：活动效益可视化，支撑复盘与优化
4. **促进用户增长**：智能推荐+内容营销双轮驱动

## 2. 功能模块

### 2.1 活动管理模块

#### 2.1.1 活动创建与编辑
- 基本信息：名称、时间、地点、类型、人数上限
- 详细描述、封面图、标签
- 费用设置（免费/付费/AA）
- 报名设置（审核制/开放制）
- 地图定位（支持手动调整）

#### 2.1.2 活动发布与展示
- 活动列表页（筛选、排序、搜索）
- 地图视图（周边活动、全国热图）
- 活动详情页（图文+报名+互动）

#### 2.1.3 报名与签到
- 在线报名（表单可配置）
- 审核流程（管理端审批）
- 签到管理（二维码/手动）

#### 2.1.4 活动状态流转
```
草稿 → 待审核 → 已发布 → 进行中 → 已结束 → 已归档
                ↓
              已驳回（可重新编辑提交）
```

### 2.2 AI辅助方案生成模块（重点功能）

#### 2.2.1 功能描述
用户有办活动的想法，但不知道如何落地。通过AI对话引导，帮助用户：
- 明确活动目标与定位
- 生成完整的活动策划方案
- 输出可执行的任务清单与时间线

#### 2.2.2 交互流程

**模式一：AI直接提出方案**
```
用户输入: "我想办一场户外露营活动"
AI输出:
- 活动定位分析
- 目标人群建议
- 场地选择建议
- 预算估算
- 时间线规划
- 风险预案
```

**模式二：AI询问引导**
```
AI: "你的活动大概是什么主题？"
用户: "音乐节"
AI: "预计多少人参加？有预算范围吗？"
用户: "100人左右，5万以内"
AI: "需要室内还是户外？有没有心仪的场地？"
...
最终输出: 完整策划方案
```

#### 2.2.3 方案内容结构
1. **活动概述**：名称、主题、时间、地点、目标人群
2. **目标与KPI**：参与人数、满意度、收入预期
3. **执行计划**：
   - 筹备期任务清单（甘特图）
   - 关键节点与里程碑
   - 人员分工建议
4. **预算方案**：
   - 收入预测（票务、赞助）
   - 支出明细（场地、物料、人员）
   - 盈亏平衡分析
5. **营销推广**：文案建议、渠道策略
6. **风险预案**：天气、安全、超售等场景
7. **复盘框架**：需要收集的数据指标

#### 2.2.4 技术实现
- 接入 DeepSeek API (v4-flash / max 模式)
- 设计系统提示词（System Prompt）引导AI输出结构化方案
- 支持多轮对话，上下文记忆
- 方案可导出为 PDF/Markdown

### 2.3 财务与效益分析模块

#### 2.3.1 财务管理
- 活动预算编制
- 收支记录（收入：票务/赞助；支出：场地/物料/人工）
- 发票与报销管理
- 自动汇总与对账

#### 2.3.2 效益分析
- 单活动ROI计算
- 同比/环比分析
- 成本结构分析
- 收益预测（基于历史数据）

#### 2.3.3 复盘报告
- 自动生成活动复盘报告
- 包含：目标达成情况、财务分析、用户反馈、改进建议
- AI辅助生成复盘总结

### 2.4 标准化流程模块

#### 2.4.1 SOP模板库
- 按活动类型分类（线下聚会、音乐节、讲座、运动...）
- 每个模板包含：策划框架、任务清单、预算模板、物料清单
- 支持自定义修改与保存

#### 2.4.2 优秀项目复用
- 高评分/高收益活动标记为「优秀案例」
- 用户可一键复制为模板
- 支持「借鉴」模式：保留框架，修改细节

### 2.5 内容与营销模块

#### 2.5.1 AI文案生成
- **活动前**：宣传文案、朋友圈文案、海报文案
- **活动中**：实时图文、直播脚本
- **活动后**：回顾文案、感谢信、精华总结

#### 2.5.2 多平台分发
- 平台内发布
- 生成适配不同平台的文案（微信公众号、小红书、微博、朋友圈）
- 一键分享功能

#### 2.5.3 回忆相册
- 活动照片上传与整理
- 自动生成相册（时间线/人物分组）
- 用户可下载/分享个人回忆

### 2.6 用户画像与推荐模块

#### 2.6.1 用户画像构建
- 基础信息：年龄、性别、地区
- 兴趣标签：运动、音乐、读书、户外...
- 行为数据：参加过的活动类型、频率、评价
- 社交关系：好友、关注、粉丝

#### 2.6.2 智能推荐
- 基于兴趣标签推荐
- 基于地理位置推荐（周边活动）
- 基于好友行为推荐
- 新活动上线通知

### 2.7 沟通协作模块

#### 2.7.1 站内消息
- 用户↔管理方一对一沟通
- 系统通知（审核结果、活动提醒）
- 消息已读状态

#### 2.7.2 工单系统
- 用户提交需求/问题
- 管理方跟进处理
- 状态追踪与满意度评价

## 3. 非功能需求

### 3.1 性能
- 页面加载 < 2s
- API响应 < 500ms (P95)
- 支持 1000+ 并发用户

### 3.2 安全
- 用户数据加密存储
- HTTPS 全站
- 敏感操作日志审计
- RBAC 权限控制

### 3.3 可用性
- 99.9% 可用率
- 数据备份策略（每日增量，每周全量）
- 灾难恢复方案

## 4. 数据模型（核心实体）

### 4.1 用户 (User)
```
- id: UUID
- username: string
- email: string
- phone: string
- avatar: string
- role: enum (admin/organizer/user)
- tags: string[] (兴趣标签)
- created_at: datetime
- updated_at: datetime
```

### 4.2 活动 (Event)
```
- id: UUID
- title: string
- description: text
- organizer_id: UUID -> User
- type: enum (offline/online/hybrid)
- category: string (音乐节/讲座/运动...)
- start_time: datetime
- end_time: datetime
- location: {lat, lng, address}
- max_participants: int
- current_participants: int
- price: decimal
- status: enum (draft/pending/published/ongoing/finished/archived)
- cover_image: string
- tags: string[]
- created_at: datetime
- updated_at: datetime
```

### 4.3 报名 (Registration)
```
- id: UUID
- event_id: UUID -> Event
- user_id: UUID -> User
- status: enum (pending/approved/rejected)
- form_data: json (自定义表单数据)
- check_in_time: datetime
- created_at: datetime
```

### 4.4 财务记录 (Finance)
```
- id: UUID
- event_id: UUID -> Event
- type: enum (income/expense)
- category: string (票务/赞助/场地/物料...)
- amount: decimal
- description: string
- invoice_url: string
- created_at: datetime
```

### 4.5 AI方案 (AI_Plan)
```
- id: UUID
- user_id: UUID -> User
- title: string
- content: text (Markdown)
- conversation_history: json (对话记录)
- status: enum (draft/converted_to_event)
- event_id: UUID -> Event (可选，转化后的活动)
- created_at: datetime
```

### 2.8 游戏化与互动模块

#### 2.8.1 活动内互动
- **签到打卡**：活动开始/结束签到，中间环节打卡
- **任务系统**：活动中设置小任务（拍照、分享、互动），完成后获得积分
- **排行榜**：活动期间积分排行，增加趣味性
- **实时互动墙**：参与者发送弹幕/图片，实时展示

#### 2.8.2 积分与徽章
- 参与活动获得积分
- 组织活动获得额外积分
- 达成特定成就解锁徽章（如"组织者之星"、"活跃参与者"）
- 积分可用于兑换优惠券、活动优先报名权等

### 2.9 奖励系统

#### 2.9.1 地图打点奖励
- 活动场地在地图显示，参与者签到打卡
- 打点累计获得奖励（积分、徽章）
- 连续打卡/多场参与奖励递增

#### 2.9.2 激励闭环
- 参与活动 → 获得积分 → 兑换福利 → 参与更多活动
- 组织活动 → 获得曝光 → 吸引更多参与者 → 形成正循环

#### 2.9.3 奖励类型
- 积分奖励：通用积分，可兑换
- 专属权益：优先报名、折扣券、限定活动邀请
- 社交荣誉：排行榜展示、徽章展示、社区认证

### 2.10 社交资产与社区

#### 2.10.1 社交资产沉淀
- **关系资产**：好友列表、关注/粉丝、互动历史
- **内容资产**：参与的相册、分享的经历、评论互动
- **成就资产**：参与/组织活动数量、获得的徽章和荣誉

#### 2.10.2 社区连接
- 基于兴趣的社群（运动群、读书会、户外群）
- 基于地理位置的社区（同城活动、周边推荐）
- 需求匹配：根据需求找人/找活动

#### 2.10.3 用户成长体系
- 用户画像 = 基础背景 + 兴趣标签 + 行为数据
- 推荐"活跃的人"：相似兴趣的活跃用户
- 社区内展示活跃用户，促进连接
