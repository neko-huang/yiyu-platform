# AI辅助活动方案生成 - 功能设计

## 1. 功能概述

帮助用户将模糊的活动想法转化为可执行的策划方案。通过AI对话引导，降低活动策划门槛，让「想办活动但不知道从何下手」的用户也能轻松上手。

## 2. 核心场景

### 场景一：AI直接生成方案
**用户输入**: "我想办一场户外露营活动，大概30人"

**AI输出结构**:

### 场景二：AI引导式提问
**对话流程**:
```
AI: 你想办什么类型的活动呢？比如运动、音乐、讲座、聚会...
用户: 音乐节
AI: 不错的想法！预计多少人参加？有预算范围吗？
用户: 100人左右，5万以内
AI: 有考虑在哪个城市吗？室内还是户外？
用户: 上海，户外草坪
AI: 需要邀请演出嘉宾吗？还是以UGC（用户表演）为主？
用户: 请几个本地乐队
AI: 明白了！让我为你生成完整方案...
[输出结构化方案]
```

### 3.2 System Prompt 设计

#### 直接生成模式
```
你是一个专业的活动策划专家。用户会告诉你他们的活动想法，你需要生成一份完整、可执行的策划方案。

方案必须包含以下部分：
1. 活动概述（名称、时间建议、地点建议、目标人群）
2. 活动流程（时间表，精确到30分钟）
3. 预算估算（分项目列出，包含人均成本）
4. 任务清单（按时间倒序，标注负责人建议）
5. 营销建议（宣传文案要点、渠道建议）
6. 风险预案（至少3个场景）

要求：
- 数据要具体，避免模糊描述
- 考虑实际可操作性
- 预算要合理，给出计算依据
- 使用Markdown格式输出
```

#### 引导式模式
```
你是一个友好的活动策划顾问。用户想办活动但想法还不成熟，你需要通过提问帮助他们理清思路。

提问策略：
1. 先了解活动类型和主题
2. 确认规模（人数、预算）
3. 了解场地偏好（城市、室内/户外）
4. 确认核心环节（表演、互动、讲座等）
5. 了解目标人群

每轮只问1-2个问题，保持对话简洁。收集完关键信息后，告知用户你将生成方案。
```

### 3.3 API接口设计

#### 创建AI对话
```
POST /api/v1/ai/plan/conversation
{
  "mode": "guided" | "direct",
  "initial_input": "用户初始想法"
}

Response:
{
  "conversation_id": "uuid",
  "ai_message": "AI的回复",
  "status": "ongoing" | "completed"
}
```

#### 发送对话消息
```
POST /api/v1/ai/plan/conversation/{id}/message
{
  "user_message": "用户的回复"
}

Response:
{
  "ai_message": "AI的回复",
  "status": "ongoing" | "completed",
  "plan_preview": {...} // 当status=completed时返回
}
```

#### 获取方案详情
```
GET /api/v1/ai/plan/{id}

Response:
{
  "id": "uuid",
  "title": "方案标题",
  "content": "Markdown内容",
  "conversation_history": [...],
  "status": "draft" | "confirmed" | "converted",
  "event_id": "uuid" // 转化后的活动ID
}
```

#### 转化为活动
```
POST /api/v1/ai/plan/{id}/convert
{
  "adjustments": {
    "title": "修改后的标题",
    "start_time": "2026-08-15T16:00:00",
    "location": {...}
  }
}

Response:
{
  "event_id": "uuid",
  "event": {...}
}
```

### 3.4 数据库设计

```sql
-- AI方案对话表
CREATE TABLE ai_conversations (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  mode VARCHAR(20) NOT NULL, -- 'guided' | 'direct'
  status VARCHAR(20) DEFAULT 'ongoing',
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- AI方案消息表
CREATE TABLE ai_messages (
  id UUID PRIMARY KEY,
  conversation_id UUID REFERENCES ai_conversations(id),
  role VARCHAR(20) NOT NULL, -- 'user' | 'assistant'
  content TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- AI方案表
CREATE TABLE ai_plans (
  id UUID PRIMARY KEY,
  conversation_id UUID REFERENCES ai_conversations(id),
  user_id UUID REFERENCES users(id),
  title VARCHAR(200),
  content TEXT, -- Markdown
  status VARCHAR(20) DEFAULT 'draft',
  event_id UUID, -- 转化后的活动ID
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

## 5. 高级特性（Phase 2+）

### 5.1 智能推荐
- 根据用户历史活动推荐场地
- 根据季节/天气推荐活动类型
- 根据预算推荐可行方案

### 5.2 模板匹配
- 分析方案特征，匹配已有SOP模板
- 推荐相似优秀案例供参考

### 5.3 协作策划
- 多人协作编辑方案
- 评论与批注
- 版本历史

### 5.4 成本计算
- 接入真实场地/物料价格数据库
- 自动计算预算合理性
- 推荐性价比更高的方案

## 6. 关键指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 方案生成时间 | < 10s | 用户等待时间 |
| 方案采纳率 | > 60% | 生成的方案被用户采纳 |
| 活动转化率 | > 30% | 方案转化为实际活动 |
| 用户满意度 | > 4.5/5 | 方案质量评分 |
