📋 OVERVIEW

项目概览

益屿是一个面向社区公益场景的轻量级活动管理平台

🎯

定位

面向社区公益组织的轻量级活动管理工具，聚焦"小而美"而非"大而全"。帮助社区用最低成本实现活动的数字化管理。

🛠️

技术栈

FastAPI + SQLite/PostgreSQL + React + TypeScript，前后端分离架构。AI 能力默认接入 DeepSeek API，成本极低。

📊

公益属性

面向社区公益组织的免费工具，零门槛使用。运营成本仅 4,000 元/年，可持续公益项目。未来可对接公益基金会、政府采购项目实现自我造血，但不以盈利为第一目标。

☁️

部署方式

云服务器部署（轻量应用服务器），年费仅约 200 元 [来源1]。支持 Docker 一键部署，维护成本极低。

🎯 PROBLEM & SOLUTION

问题与方案

⚠️ 社区活动管理的痛点

  • 社区活动全靠微信群接龙，报名混乱、信息难追溯
  • 活动照片散落在各人手机里，没有统一的回忆沉淀
  • 财务记录靠手工记账，对账困难，难以透明公开
  • 每次活动从策划到复盘，重复劳动多，缺乏模板沉淀
  • 社区负责人多为志愿者，没有技术背景，无法使用复杂工具
  • 传统活动管理 SaaS 动辄数万元/年 [来源11]，公益组织无力承担

✅ 益屿的解决方案

  • 完整的活动发布、报名、签到管理流程，替代微信群接龙
  • 活动回忆相册，参与者可上传照片，自动归档
  • 财务收支记录透明化，支持按活动维度统计
  • AI 辅助生成活动方案、多平台文案，减少重复劳动
  • SOP 模板库，沉淀活动经验，新人也能快速上手
  • 年运营成本约 4,000 元 [来源1-5]，公益组织完全可承受

⚡ FEATURES

功能矩阵

已实现的核心功能模块

📅

活动管理

活动发布、编辑、状态流转（草稿→发布→进行中→完成→归档）。支持在线/线下/混合活动类型。

📋

报名签到

用户报名、审批、签到全流程管理。支持活动名额限制、报名表单自定义。

💰

财务管理

活动级收支记录，支持收入/支出分类，自动汇总统计。适合公益组织透明公开需求。

🤖

AI 方案生成

输入活动主题，AI 自动生成活动方案（含时间线、预算、物料清单）。默认接入 DeepSeek API。

📸

回忆相册

活动结束后，组织者和参与者可上传照片，形成活动专属相册，永久保存美好回忆。

🏆

游戏化成就

积分 + 成就系统，激励社区成员持续参与。支持自定义成就和积分规则。

💬

讨论区

每个活动独立讨论区，参与者可交流互动，提问反馈。支持评论和回复。

📝

SOP 模板库

活动 SOP 模板沉淀，涵盖读书会、环保活动、亲子活动等常见类型，新活动可一键复用。

📢

AI 多平台文案

一键生成活动宣传文案，适配微信群、公众号、小红书等不同平台风格。

🔍

搜索与推荐

活动搜索、按类别/标签筛选、基于用户画像的个性化推荐，帮参与者发现感兴趣的活动。

📊

活动复盘

活动结束后生成复盘报告，记录评分、优缺点和改进建议，持续优化活动质量。

👤

用户画像

用户兴趣标签、活动偏好分析，支持个性化推荐和社区成员画像洞察。

🧭 STRATEGY

长期投资策略

五个核心问题 + 盈利模式，回答投资人最关心的根本问题

1

介入什么行业？需要什么资产？

行业：社区活动管理数字化。这是一个 212.7 亿元且仍在增长的市场 [来源6]，但社区公益细分几乎空白。全国 64.7 万个自治组织 [来源10]、92.4 万家社会组织 [来源16]，大量还在用 Excel + 微信群。

资产：不需要建筑物、机器或设备。 核心资产是 15,000+ 行代码、13 个数据模型、AI 能力。一台电脑 + 一台云服务器 = 全部生产工具。这是典型的轻资产模式。

2

资金来源？会不会引入其他所有者或借钱？

✅ 资金来源

  • • 自筹起步——¥4,000/年，个人完全可负担 [来源1-5]
  • • 公益基金会扶持——腾讯/字节公益 AI 工具库计划 [来源12]
  • • 政府购买服务——街道信息化采购经费 [来源10]
  • • 社区订阅收入——未来增值服务收费
  • • 企业 CSR 赞助——企业社会责任合作

🔒 所有权策略

  • • 现阶段不引入外部所有者——单人决策效率高
  • • 不借贷——4,000元/年的成本无需杠杆
  • • 未来如需规模化，优先考虑公益基金会捐赠而非股权融资
  • • 可注册民办非企业单位（民非）承接政府项目，不涉及个人分红
  • • 若商业化加速，可设立有限责任公司，创始人保留控股权
3

日常财务活动如何管理？

📥 客户收款

  • • 初期无客户收款（免费使用）
  • • 未来订阅收入 → 微信/支付宝商户号
  • • 政府/基金会拨款 → 对公账户
  • • 飞书多维表格实时记录每一笔收入

📤 供应商付款

  • • 供应商极少（云服务器、域名、AI API）
  • • 全部自动扣费或年付，无需月结管理
  • • 年总支出 ≈ 4,000 元，个人账户即可管理
  • • 用飞书多维表格记账，年度对账一次

💡 一句话总结：年流水不超过 5,000 元，无应收应付管理，飞书多维表格就是财务系统。费用产生后再复杂管理也不迟。
